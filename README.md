# Skin Disease Detection

Веб-приложение для предварительного анализа кожных заболеваний по фотографии.  
Разработано в рамках дисциплины «Технологии разработки программных приложений» (РТУ МИРЭА, 2026).

## Описание
Пользователь загружает фото участка кожи → система детектирует наличие кожи → ML-модель классифицирует состояние → выводятся диагноз, уверенность модели, оценка тяжести и персонализированные рекомендации по уходу.  
Приложение предназначено для образовательных и демонстрационных целей и не заменяет очную консультацию врача-дерматолога.

## Стек
- Python 3.10+, Flask
- PyTorch, OpenCV, Pillow
- setuptools, Sphinx

## Возможности
- Загрузка изображений с drag-and-drop и мгновенным предпросмотром
- Инференс baseline-модели (RandomForest) на CPU
- Оценка тяжести поражения и числовой уровень уверенности (`confidence`)
- Автоматическая генерация рекомендаций по уходу
- Полная контейнеризация через Docker + Gunicorn
- Автодокументация API и модулей через Sphinx

## Запуск
###  Локальный запуск
```bash
# 1. Клонирование и переход в директорию
git clone https://github.com/Eliz-Kory/skin_disease_detection.git
cd skin_disease_detection

# 2. Виртуальное окружение
python -m venv .venv
.venv\Scripts\activate   # Windows
# source .venv/bin/activate  # Linux/macOS

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Запуск сервера
python app.py
# или через Gunicorn:
gunicorn --bind 0.0.0.0:5000 --workers 2 app:app
```

Откройте в браузере: http://localhost:5000

###  Запуск через Docker

```bash
# Сборка образа (без кэша для применения свежих правок)
docker build --no-cache -t skin-app .

# Запуск контейнера
docker run -p 5000:5000 --rm skin-app
```
